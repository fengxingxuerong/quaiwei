# 语体指数 `registerIndex`（v0.9.82）

> 类型：当前口径。改了 `src/engine/register-metrics.ts` 就同步改这份。
> 一句话：量**书面度**的第二把尺，与 aiScore 并列、不并入、不互相替代。

## 1. 为什么需要第二把尺

`artifacts/human-corpus/probe-inject.ts` 在 21 篇真人文本上做双向注入（2026-10-14 实验，
2026-11-04 复测同口径）：

| 注入方向 | aiScore 方向正确 | Δ 均值 |
|---|---|---|
| 注入 AI 套话（应升） | 19/21 = 90% | +14.6 |
| 书面化替换（应升） | **0/21 = 0%** | 0.0 |
| 口语化替换（应降） | **2/21 = 10%** | −0.6 |

原因不复杂：aiScore 的检测项（套话词表 / 病词 / 孤立连接词 / 垫词独句 / 句长节奏）全部只对
**词表命中的套话与结构缺陷**敏感。「大致 → 差不多」「倘若 → 要是」这类纯语体替换不进任何检测器，
分数纹丝不动——只有 22 处 / 56 处命中，方向还基本是错的。

同一批样本换 `registerIndex` 复测：

| 注入方向 | registerIndex 方向正确 | Δ 均值 |
|---|---|---|
| 口语化替换（应降） | **15/21 = 71%** | −3.9 |
| 书面化替换（应升） | 10/21 = 48% | +1.5 |

书面化那条只有 48%，是因为维基正文口语词本就极少（全样本仅 22 处可换），召回上限被样本卡住，
不是指标失效。真人基线 `registerIndex` 中位 **88**（21 篇：61~100）——维基正文本身就是书面语，
落「偏书面/公文腔浓」属预期。

## 2. 为什么不直接给 aiScore 加权

1. **书面 ≠ AI。** 真人写的政务报告、维基正文、技术文档本来就满是书面标记。并进去会把真人
   正式文本推进"可疑带"（`humanize-metrics.ts` 灰区 H6/H8 的教训：继续上调权重就是真误伤）。
2. **aiScore 刻度自守。** v0.9.83 前「x 轴已被 18 个送检锚点标定、带棘轮门禁」是反对并轨的
   主要理由；那套标定（`test:calib`）已随标定子系统整体移除。现在并轨反对的理由只剩第 1 条——
   而这一条本身就足够：**书面 ≠ AI**，并轨必然误伤真人正式文本。

所以它是**并列的第二把尺**：同一篇稿前后对比有意义，跨文本绝对值照样不可比。

## 3. 口径

```
index = clamp(0, 100, 50 + 50·min(f, CAP)/CAP − 50·min(c, CAP)/CAP)
CAP = 8 / 千字
```

- `f` / `c`：书面 / 口语标记的每千字命中密度。分母**只数 CJK 字符**——英文夹注、数字、
  空白不摊薄密度。
- **线性带顶**而不是差值的 tanh：后者在 1:1 词面互换下 `f + c` 守恒 ⇒ `f − c` 守恒，
  「口语→书面」方向会整个失效。线性带顶下每跨一次边界换一对词，两侧各动一格，两个方向都有梯度。
- 50 中性，±50 封顶（每千字 8 个标记即给满单向权重，约等于平均每 125 字一个）。
- 标签带：`≥80` 公文/书面腔浓 · `60~79` 偏书面 · `40~59` 中性 · `20~39` 偏口语 · `<20` 口语。
- 无 CJK 字符时返回 50 / 中性（不瞎猜）。

返回结构完整字段见 `RegisterReport`：`index` / `label` / `formalHits` / `colloquialHits` /
`formalPer1k` / `colloquialPer1k` / `countedChars`。

## 4. 怎么用

```ts
import { registerIndex } from "./engine/register-metrics";

const before = registerIndex(原文);
const after = registerIndex(产出);
// 只比同一篇的前后；别拿两篇文章的绝对值互比
```

界面在结果区显示 `语体 100 → 50 · 中性`，tooltip 明说「量的是书面度，不是 AI 味；
真人公文会得高分」。MCP 的 `detect` 返回里也带这一维（`aiScore`/`detectAI` 对语体替换是盲区，
这是并列补充）。

## 5. 已知边界

1. **它测语体，不测 AI 味。** 真人公文得高分是正常的，不是误报。
2. 词表是简中的；英文、繁中不在调优范围（与引擎主边界一致）。
3. 与任何检测器官方分无标定关系。
4. 全表直配（substring）。单字词已逐个核过复合词噪声——凡直配会命中口语高频词的单字
   （之/其/该/即）一律不收，宁缺毋滥。新增词前请先跑 `probe-inject` 看方向有没有变好。

# 单测
