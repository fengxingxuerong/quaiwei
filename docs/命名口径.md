## 1. 结论

**不改 repo slug，统一对外名称「趣AI味 QuAiWei」。**

| 选项 | 判断 |
|---|---|
| 改 GitHub 仓库名 | ❌ 会断 Pages、release 直链、npm 包名、全部文档链接与已售商品文案；收益只是躲开两个同名仓 |
| 统一中文全名 + 索引元数据 | ✅ 零断链；搜索命中靠 description / topics / 索引榜条目，不靠 slug |
| 在两个撞名仓下争同名 | ❌ 对面 star 是本仓 188 倍 / 18 倍，硬碰没有收益 |

`quaiwei` 继续做**包名 / CLI / MCP / 技术标识**；`趣AI味 QuAiWei` 做**产品名 / 搜索词 / 对外第一屏**。
两者不是二选一，是分工。

- `npm run build` 要求工作区干净，且把 **HEAD** 盖进产物；
- v0.9.88 Release 已发布，产物指纹 = `2079227`；
- 任何 commit 都会让 HEAD 变而产物盖的还是旧值 ⇒ 必须重走
  `build → rebuild-app.cjs → prune-dist.cjs → verify-pruned.cjs → 重打 219MB zip → _publish.cjs --replace`。

⇒ 本轮所有仓库内改动**保持未提交**，等下次发版时一起 commit + 重打包。
这不是遗漏，是为了不破坏已发布 release 的可核验性。

4. 撞名两家不提、不比、不引流，只在内部对标文档里留痕。
