## 4. 五条结论

### 4.1 撞名撞了两次，且都比本仓星多

**[事实]** `LifelongLazyLearner/qu-ai-wei`：697★，2026-04-21 建，v0.9.1，最后提交 2026-09-10，
简体中文去 AI 味 skill，主张同样是"保留事实、判断、正式程度和原文声口"，是 10-26 周报里已记的那一个（本仓 232 倍）。
**[事实]** 本轮新增：`baibanbao/qu-ai-wei`：73★，最后提交 2026-09-23，同样是简体中文去 AI 味（本仓 24 倍）。

站内搜 `quaiwei` 先出这两家。改名（或统一用中文全名"趣AI味"）是运营动作，拖一天亏一天。

### 4.2 "唯一诚实"这条判断站不住

10-26 周报写"真正的空位是唯一一个把'没做到什么'写进对外页面的中文工具"。**不成立**：

- [事实] blader 正文写「Getting past AI detectors is not a goal, and detectors still flag most of its output」
- [事实] op7418 写「它不能证明文章由谁撰写，也不保证通过任何 AI 检测器」
- [事实] sgaofen 有完整 Limitations，连"偶尔整段用错语言""Windows 版没在真机跑过"都写了
- [事实] swaylq 写 CNKI/维普/万方没公开 API、PaperPass 与朱雀有腾讯 T-Sec 验证码，所以"不盲信第三方检测器分数"

诚实已经是标配，而且不换来 star（榜上第 1、第 3、第 4 名都没写这层）。
**真正没人做的是第二层**：把自己的失败**测量数字**公开成可复现页面——
"本地 2 / 外部 90"、"6/18 标定点漂移"、"凭证 0/18"这种能直接打自己脸的数。
这一层目前只有本仓在做，但**它没换来任何可见度**，说明"诚实"在这个赛道是无效定价：
买的人不读，读的人本来就不买。

### 4.3 离线这条线被一款 12B 模型重新划了

**[事实]** [sgaofen/humanizer-local-model](https://github.com/sgaofen/humanizer-local-model)：546★，Apache-2.0，
基于 `google/gemma-4-12B` 微调，2.86 万对"AI 草稿 → 真人原文"监督数据，中英双语，
提供 GGUF 量化（3.9GB）与 macOS/Windows 桌面 app，HuggingFace 有权重。
自报：英文 210 篇里 11 篇被判 AI；420 篇改写里 376 篇无事实问题；
**中文 204 篇里 149 篇无事实问题（约 73%）**。

这是**结构性威胁**，不是又一个 skill：它同时满足"离线 + 不要 Key + 中文 + 结构级重写"，
正好落在本仓"不篡改原文"与"结构级去味须走 LLM"两块挡板之间。
本仓的护城河是确定性词表、可复现、不新增事实；它的反证是"我也不联网，但我能打散结构"。
代价是 4GB 权重、逐台机器的算力，以及中文 73% 的事实保真。
**这两个数要摆在一起说，而且引用它的原文，不能引用自己的方便版本。**

### 4.4 检测闭环本仓独一份，但独一份的原因不全是好事

**[事实]** 这轮扫到的 33 项里，没有第二家做"可配置外部检测器 + 多档横向 + 批量报告"：
- AIWriteX 自称"过朱雀"，同一份 README 又写「朱雀 AI 检测过于变态，对抗非一日之功，需做长远计」
- swaylq 明说接不进去（验证码）
- 其余 skill 类项目不碰检测
- lynote 有配套开源检测器，但是自研的，不是外部真值

最接近的是 `qoqu/anti-zhuque`（28★，纯标准库）：做"诊断 → 出改写 prompt → 再诊断"，
听起来是本仓这条路，但两次诊断用的都是**自家代理指标**（突发性、困惑度代理、结构指纹、跨段一致性）——
换了名字的同一把尺子量自己。这正是本仓 README 顶部警告的那种自证，所以不算同类能力，
也不该被拿来当"已经有人做了"的证据。

本仓的 `--detector-url` 是唯一"用别人的尺子量自己"的设计。但**凭证覆盖率 0/18** 意味着
这条闭环目前跑出来的数，证明力比不上它读起来的样子。独一份的价值取决于**下一次送检能不能 seal 入账**，
不取决于接口写得多全。

### 4.5 活跃度不在同一量级，但头部已经停了

**[事实]** 最后提交：blader 10-16、**op7418 09-23（停一个月）**、**stop-slop 2026-03-17（停七个月）**、
im-not-ai 10-12、**lieflat 08-24（停两个月）**、academic-humanizer 07-03、
**ai-flavor-remover 2025-04（停一年半）**、qu-ai-wei 09-10。本仓 10-25 还在推。

前 14 名里有 5 个停更一个月以上。高 star 里相当一部分是**存量遗产**，
但这不是可以慢慢追的理由——skill 类项目迁移成本几乎为零，谁停下来用户就换谁。

## 6. 边界

- star / fork 数取自 `scripts/scan-github-sector.mjs` 本轮输出（2026-10-26 20:01 UTC）。
  同一仓库的 HTML 与 API 读数会差几十（如 blader 60,979 vs 60,949），是抓取时刻与缓存差异，不是矛盾。
- 脚本里"最后提交"取自 `commits.atom`，**可能落后**于 API 的 `pushed_at`（如 AIWriteX 显示 09-17，
  API 报 10-26）。要精确日期请用 API 复核；本文的日期以脚本输出为准，不作强结论。
- 竞品 README 里的自报数字（16/16、95%、42 案例、149/204、11%）**均未复现**，只当话术证据。
- 本仓能力面引用 SCORECARD（数据截止 2026-10-26，v0.9.81），未在今日重跑。
- 未覆盖：闭源商业站（朱雀、PaperPass、GPTZero）与付费 humanizer SaaS，本文只比 GitHub 公开仓库。
