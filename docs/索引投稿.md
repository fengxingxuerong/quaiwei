**正文**

```text
Please consider adding:

**URL:** https://github.com/fengxingxuerong/quaiwei

**Why it fits:** Simplified-Chinese de-AI-flavor tool that runs offline as a deterministic
TypeScript engine (no API key, no network). Ships as a desktop app, a web demo, a CLI
(`ai-humanizer`), an agent skill (`SKILL.md`) and an MCP server (`quaiwei-mcp`: humanize_text /
detect_ai / quality_report). Being a fixed-seed rule engine rather than a prompt, it can be
tested: 2,377 automated tests, a 4,080-run structure-fidelity sweep, and a published scorecard
listing what it cannot do (SCORECARD.md). It does not claim to pass any detector, and says so
in the README.

**Type:** Writing humanizer (deterministic engine + CLI/MCP; not a prompt-only skill).

Disclosure: I am affiliated with the project (author).
```

三点说明，别在投稿里加：

1. **不写"过检率"**。榜上很多条目挂"95% 通过 Turnitin"，本仓没有这种数据，写上去就是撒谎。
2. **不写星数**（现在 3 星）。他们自己会去读仓库并打分，写少了不加分，写多了是骗。
3. **必须写 Disclosure**。现有那条投稿 issue 就是自己声明了关联，这是这个榜的默契。
