# C 类窄守卫：离线模拟（2026-11-12，**未上线**）

`evidence/collateral-collapse-2026-11-12/README.md` 把 3 条「使得」悬空判为唯一真语病，
并写明「改切句守卫需单独立项 + 双席 A/B」。本文件是立项前的影响面量化。

## 结论先行

| 规则 | 覆盖 C 类 | 新增否决（现有放行的 1724 个真人切点） | 判定 |
|---|---|---|---|
| R1 致使+比较状语悬空 | 1 条 | **0（0%）** | 零影响面 |
| R2 给予+目的「来」悬空 | 1 条 | **0（0%）** | 零影响面 |
| R3′ 5~6 字短段无真谓语 | 1 条 | **298（17.3%）** | 风险大，需 A/B |
| 合并 | 3/3 | 298（17.3%） | — |

⇒ **风险全在 R3′**。R1/R2 是真正「窄」的守卫，R3′ 会挡住六分之一的现有切分点。

## 三条 C 类 front（切点位置各不相同）

| id | 产出前半句（front） | 现有 `fragmentFrontCanStand` | 被谁拦下 |
|---|---|---|---|
| 集成电路 | 这些电路的小尺寸使得与板级集成相比 | 放行 | R1 |
| 量子力学 | 则这光子可以给予足够能量来 | 放行 | R2 |
| 5G | 更多的蜂窝 | 放行 | R3′ |

**不是一条「使得」守卫能盖住的**：第一条切在状语尾「相比」，第二条切在目的「来」，第三条切在 5 字名词残片。

## 候选规则（≤10 个关联词/形态，满足立项约束）

```
R1  /(?:使得|致使)[^，。；：]{0,24}(?:相比|相较|而言|来说)$/
R2  /(?:给予|提供|带来)[^，。；：]{0,20}来$/
R3′ lastSeg.length <= 6 && !NP_PREDICATE_RE.test(lastSeg)
```

- R1 只拦 4 个比较状语收尾，R2 只拦 3 个给予类动词 + 「来」收尾，都刻意收得很窄。
- R3′ 是把现有 `lastSeg.length <= 4` 门槛提到 6，谓语判据从单字宽表
  「`CLAUSE_PREDICATE_RE`」（含「更」「使」「以」等，名词内部大量嵌入 → 误判有谓语）
  换成 `NP_PREDICATE_RE`（双字谓词 / 体标记）。
- 粗版 R3（只按长度 ≤6、不配谓语判据）也测过：284 个（16.5%）。
  换精确谓语判据后反而到 298 个 —— 因为 `NP_PREDICATE_RE` 比单字表更严。

## 模拟方法

- 语料：21 篇真人维基长文，按句末标点切句，每句取最后一个「，」前的 front → **2306 个候选**。
- 现有守卫 `fragmentFrontCanStand` 放行 **1724 个**；逐条规则只在这 1724 个上统计「新增否决」。
- 完全不碰 `src/`：脚本 `scripts/collateral-c-guard-sim.ts` 把候选规则写成局部函数，离线跑。

复现：`npx tsx scripts/collateral-c-guard-sim.ts`（不联网、不改字）。

## 为什么本轮不上线

1. **A/B 未执行**：8080 网关离线；18080 返回 401（`Invalid or missing proxy API key`）；
   本机 3 条历史凭证全部无效 ⇒ 双席配对跑不了。
   记忆的硬约束是「改切句守卫两次判退化（`897f738` 90 票 0.222、`d421f38` 三次失败），
   需单独立项 + 双席 A/B」，**没有 A/B 就不能声称验收通过**。
2. 即使 R1/R2 影响面为 0，也只统计了 21 篇真人长文的候选切点；
   `realcase` 23 篇、4080 次 `sweep:format`、多种子棘轮未扫。
3. R3′ 的 298 个新增否决里可能本来就有缺陷（「现有放行」≠「合法」），
   但也可能是正常切分被误挡 —— 这个区分只能靠人判。

## 限制

- 「现有放行」不等于合法，新增否决未必是误伤。
- front 抽取用 `lastIndexOf("，")`，与引擎 `findSplitPoint` 的 mid 选点不完全一致。
- 只覆盖维基百科体长文，未扫营销/公文/技术体。
- `NP_PREDICATE_RE` 在模拟里复制了一份，将来产品实现必须引用 `humanize-primitives.ts` 的真常量。
