## 四个根因（27 条 = 17 + 5 + 3 + 2）

| 类 | 条数 | 机制 | 产出形态 |
|---|---|---|---|
| A 破折号转逗号 | **17** | 整篇 `——` 超过 1 个时，第 2 个起被替换成 `，` | `A——B（解释）` → `A，B（并列）` |
| B 省略号压缩 | **5** | `……` 压成 `…`，并在其后补句号 | `A……B` → `A…，B。` |
| C「使得」悬空 | **3** | 切句点落在 `使得…相比` 的状语后 | `A使得B相比，C` → `A使得B相比。C` |
| D 引号/书名号截断 | **2** | 引号内文本被当作句边界 | `“死而後已”成為…` → `“死而後已”` 独立成句 |

### A 类：破折号转逗号（17 条，占 63%）

原文「瑰丽高峰——莲花峰，海拔1864米。」→ 产出「瑰丽高峰，莲花峰，海拔1864米。」

不是 v0.9.85 修过的「破折号变句号」——那个确实修好了。现在是**变逗号**：
`humanize-metrics.ts:487` 判定「整篇最多 1 个破折号，AI 爱滥用」，
超额部分被替换成逗号。第一个破折号保留，第二个起全部降级。

后果：

- 「A——B」在中文里 B 是 A 的解释/同指（「瑰丽高峰」=「莲花峰」）；
  换成逗号后读成并列（两座不同的峰），**语义关系被改写**。
- 基准台的 `collapse` 检测器把它判成「残句，谓语已丢失」——因为「瑰丽高峰，莲花峰」这个逗号分句确实没有谓语。

典型样本：
```
「形式灵活的新文体——“杂文”」        → 「形式灵活的新文体，“杂文”」
「瑰丽高峰——莲花峰」                 → 「瑰丽高峰，莲花峰」
「設立了漢朝對西域的直接管轄機構——西域都護府」 → 「…機構，西域都護府」
「包围着细胞的是——通常包括细胞壁」    → 「包围着细胞的是，通常包括细胞壁」
```

### B 类：省略号压缩（5 条）

原文「他始终没有研究清楚……正因为这样，才有了后来的争论。」
→ 产出「他始终没有研究清楚…，正因为这样。才有了后来的争论。」

两个动作叠在一起：`……` → `…`；然后在「正因为这样」后插句号。
「正因为这样」是承上启下的关联语，后面断句直接造出病句。

### C 类：「使得」悬空（3 条，**唯一的真语病**）

```
原文：这些电路的小尺寸使得与板级集成相比，功耗大幅下降。
产出：这些电路的小尺寸使得与板级集成相比。功耗大幅下降。
```

「使得与板级集成相比」是一个未完成的介宾结构，句号切在状语后 ⇒ 前一句无谓语落点、后一句丢了主语关联。
同类样本另两条：

- 量子力学：「则这光子可以给予足够能量来使得金属表面的一个电子」→ 在「能量来」后断
- 5G：「更多的蜂窝使得5G网络基础设施比以前的蜂窝网络每」→ 在「更多的蜂窝」后断

机制：切句按长度/节奏找逗号，**不看逗号后的成分能否独立成句**。
`A使得B相比，C` 里的逗号不是句法边界，只是长状语的分隔。

### D 类：引号/书名号截断（2 条）

```
原文：「死而後已”成為无数仁人志士的座右铭」
产出：「死而後已”」独立，后半句另起
```

引号闭合处被当句子边界。同类：「丝绸之路并非是一条 “路”，而是一张网」→「丝绸之路」独立成句。

## 严重性分级与处置建议

| 类 | 严重性 | 建议 | 理由 |
|---|---|---|---|
| C「使得」悬空 | 🔴 高 | **该修**：切句守卫加「关联词/介宾结构内不断句」 | 产出是病句，真人稿也会被改坏 |
| B 省略号 | 🟡 中 | 可选修：`……` 不压、或不在此处补句号 | 压缩本身可接受，补句号才是问题 |
| D 引号截断 | 🟡 中 | 可选修：引号内视为不可分 | 频率低（2 条），但形态明显 |
| A 破折号转逗号 | 🟢 低 | **不改**，但要承认语义损失 | 这是「压缩 AI 滥用破折号」的既定策略；改成删破折号反而更伤原文 |

## 为什么本轮不改代码

1. **改切句守卫属于「结构层」，历史上两次都测出退化**：
   `897f738` 的结构收敛 90 票只赢 0.222；`d421f38` 三次切句收敛失败。
   记忆里的处置是「改切句守卫会重蹈 90 票退化方向，需单独立项」。
2. **C 类只占 3/27**，但守卫一旦收紧（「逗号后不是独立小句就不断句」），
   会同时挡住大量**合法**的切分点，碎句化率会掉回去——那正是 v0.9.85 想解决的问题。
3. 要动就必须配 A/B 验收（双席配对强制选择），而不是只看 `collapseIssues` 下降。
   **单看指标下降就改，是 90 票那次的教训。**

⇒ 本报告的交付物是**归因与分级**，不是修复。下一步若要做，正确顺序是：
先写一个「关联词不断句」的窄守卫（只覆盖 `使得/正因为/并非/由于` 等 ≤10 个词），
单独 A/B 验收，不与碎句化率指标一起调。
