# convergence A/B 异源双席配对强制选择 · 2026-11-26

## 一句话结论

用**异源双席**（DeepSeek v4.1-flash + Bailu-2.8，两个不同网关不同模型家族）对 21 篇中文语料做配对强制选择：
**收敛版（B 臂）被判「更像 AI」的比例只有 21.4%（6/28 票，p=3.7e-3）**——方向指向收敛版更像人。
但两个评委之间存在**显著异质性（Fisher p=0.027）**，A 席 14/14 零方差，因此**只作方向性证据，不上线**。

## 方法

| 项 | 取值 |
| --- | --- |
| 语料 | `artifacts/human-corpus` 全部 21 篇中文真人文本 |
| A 臂（free） | `humanize(text, {intensity:0.6, seed:20260905})` 默认碎句版 |
| B 臂（converged） | 同参数 + `convergence: true` 收敛版 |
| 超长处理 | 两臂**等长截断**到 9000 字（8 篇），规避评委 400；两臂截同样字数保持配对公平 |
| 两臂相同 | 0 篇（确认差异真实） |
| 席位 A | `https://discovery-api.intern-ai.org.cn/v1` · `deepseek-v4.1-flash-1017` |
| 席位 B | `https://bailucode.com/openapi/v1` · `bailu-2.8` |
| 问法 | 「哪一段更像 AI 生成」强制二选一 |
| 协议 | `STRICT=1`：只认纯「甲/乙」或严格 JSON `{"pick":"甲"}`；非严格记无效票，**绝不猜字** |
| 位置偏置 | `flip_for`（逐字复刻 `ab_accept.py`）按 (id, seat) 哈希决定甲乙顺序，两席顺序不同 |
| 采样 | `MAX_TOKENS=512`、`TEMPERATURE=0.6` |

## 结果

| 指标 | 数值 |
| --- | --- |
| 总票 | 42（21 篇 × 2 席） |
| 干净票 | 35（83.3%） |
| HTTP 错误 | 2（席位 A 429 限流） |
| 非严格输出 | 5（记无效票） |
| 席位 A：B 臂被判更像 AI | **0 / 14**（p=1.2e-4） |
| 席位 B：B 臂被判更像 AI | 7 / 21（p=0.19，不显著） |
| 两席同篇且都干净（交集） | 14 篇 / 28 票 |
| 交集内 B 臂被判更像 AI | **6 / 28 = 21.4%**（p=3.7e-3） |
| 交集内两席一致 | 8 / 14（57.1%） |
| 两席都说「B 更像 AI」 | **0 篇** |
| 两席都说「A 更像 AI」 | 8 篇 |
| 两席异质性 | **Fisher p=0.027（显著分歧）** |

## 必须一起看的三件事

### 1. 方向一致，但强度差异极大

- A 席 14 票**全部**判默认碎句版更像 AI（零方差），认为收敛版明显更像人。
- B 席只有 7/21 判收敛版更像 AI，接近抛硬币偏一侧。
- 两席异质性 Fisher p=0.027 ⇒ **不能把 35 票合并成单一刻度**。
  项目纪律：合并前必须先看异质性；这里明确不过关。

### 2. A 席零方差但非位置偏置

A 席在「甲=free 臂」时选乙（=converged），在「乙=free 臂」时选甲（=converged），
两个位置下都指向同一臂 ⇒ 是**内容判断**而非位置偏好，位置已由 flip 抵消。
但 14/14 的零方差本身说明该评委对这类差异极不敏感或判定阈值极端，不能单独当刻度。

### 3. B 席有明显第二位偏好

B 席 17/21 选「乙」（81%），存在位置偏好；因 flip 在两席间平衡分布，聚合 bWin 未被系统性带偏，
但方差被抬高。

## 不能推出的结论

- **不能上线 convergence**：单 seed、单强度（0.6）、无多种子多强度扫描；两席显著异质、A 席零方差；
  问的是「哪段更像 AI」代理题，不是真人判别真值。
- **不能说 aiScore 变好**：本轮未评估本地代理分。
- **不能外推到其他体裁/语言**：21 篇均为中文真人语料，8 篇被截断。
- **不能把 21.4% 当刻度**：它只说明在这批样本、这两个评委下方向如此。
