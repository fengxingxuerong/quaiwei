## 二、新增数字守卫

### 判据

`addedNumericFacts(source, output)`：产出里出现、**数值在整个原文中一次都没出现过**的数量事实。

- 数值出现过、只是量纲变了（`126.75 亿元` → `126.75 万元`）**不算新增**——那已经由
  `changedUnits` 报过，重复报等于同一处失真喊两次。
- 归一化原样继承 `quantityFacts`：中文数字互认、量词不算量纲、无单位单个数字不收、
  `X200` / `iPhone15` 这类标识符不收。

### 实测（真实产出，非构造）

| 语料面 | 组数 | 命中 | 命中率 | 命中内容 |
|---|---:|---:|---:|---|
| `--api` 单轮 glm-5.3-flash（0.9 档 / 0.6 档） | 46 | 2 | 4.3% | `5.6 个百分点`（C16，0.9 档）、`1500`（C4，0.6 档） |
| 本地引擎（realcase 23 篇，seed 20261015 / 强度 0.9） | 23 | 0 | 0% | — |

两例命中**都是真缺陷，都是算术派生**：

- C16 招股风险提示：原文 `21.4%` 与 `15.8%` 都在，产出多出「比营收增速低了 **5.6** 个百分点」。
- C4 产品文案：原文 `4999 元` / `6499 元` 都在，产出多出「差价 **1500** 元」。

数值算对了，但原文从没给过这个口径。财报/招股/招标场景里读者会拿它去对披露，
**假阳性 0/69**（46 + 23）。

### 为什么不是"编造复核"的重复

`fabricationReview` 走 LLM，判的是"新增事实性断言"，成本高、只在 strict 且深度模式生效；
本轮这条是**纯本地、零 API、确定性**，单轮 `--api --no-deep` 路径同样覆盖（该路径此前只有
`missingNumericFacts`，反方向完全空着）。

## 三、C 类窄守卫 R1/R2

### 加的两条

```ts
if (/(?:使得|致使)[^，。；：]{0,24}(?:相比|相较|而言|来说)$/.test(front)) return false;
if (/(?:给予|提供|带来)[^，。；：]{0,20}来$/.test(front)) return false;
```

对应 C 类三条里的前两条（第三条「更多的蜂窝」是 5 字名词残片，属 R3′，未上线）。

### 影响面：21 篇真人长文逐篇对比（seed 20261113，强度 0.9）


## 四、边界与仍未做

1. **R3′（短段门槛 4→6 + 双字谓词判据）没上线**：模拟里新增否决 298/1724 = 17.3%，
   这 298 个未必都是误伤，但判不了 ⇒ 需要双席 A/B。
2. **双席 A/B 本轮仍不可执行**：`8080` 离线、`18081` 离线、`8326` 需 key 且历史 3 条凭证全 401。
   ⇒ 本轮两条改动都**只做确定性验证 + 逐篇全量对比**，任何"效果更好"的说法不成立。
3. 把模糊表述改成精确值（`近一半` → `48%`）会被算成新增。语义上确实是新增量化，
   但对普通散文可能是过度保守 ⇒ 所以维持"默认只提示、strict 才否决"。
4. 只覆盖 23 篇短稿 + 21 篇长文；长 AI 稿（`artifacts/ai-corpus-long/`）没有对应改写产出，
   未纳入。
