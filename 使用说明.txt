一、这是什么？
  把 AI 写的文章改得更像人写的，两种引擎：
  ① 本地引擎：零依赖、离线、零成本，"换词不换骨"（削套话与标点指纹；中英空格跟随原文排版，不再强行删除）；
  ② LLM 深度模式（推荐，配 API 后自动接管）：改写 → LLM 评分 → 质检 →
     交叉评判 → 定向修订的多轮闭环，能打散段落结构和句序，实测同稿
     AI 味降幅远超纯本地档。

二、文件夹里是什么？
  一键启动.bat         → 日常用：双击自动装依赖并启动
  环境依赖安装.bat     → 只在新机器/装完系统后跑一次（装 Node 环境）
  使用说明.txt         → 本文件
  src/ dist/ 等        → 程序本体（不用管）

三、环境要求（唯一）
  Node.js 22.12 或更高版本（20.19+ 也可），下载：https://nodejs.org/（选 LTS 版一路下一步）
  说明：桌面版 QuAiWei.exe 与在线版不需要 Node；只有「双击一键启动.bat 跑 Web 版」这条路要。

四、怎么启动？
  双击「一键启动.bat」→ 自动打开 http://localhost:5173
  手动方式（等价）：npm install && npm run dev

五、配置 LLM（可选，效果更强）
  点右上角「设置」：
  ① Base URL / API Key / 模型（任意 OpenAI 兼容服务商）；
  ② 深度模式默认开启：多轮"改写→评分→再改写"闭环，达标线默认 10 分，
     评判员首轮打分偏高（严评）时自动按首轮分锚定放宽（看结果 note 可见）；
     v0.9.14 起反向也收手：首轮分已经落进"人写带"（≤28）就不再开修订轮
     （实测两轮修订都没拿到更优分，继续追只是白烧调用），达标线本身没有放宽；
  ③ 可配交叉评判模型（建议与改写模型不同家族，消除自评偏差）与备选改写模型
     （深度模式首轮双模型竞争择优）；
  ④ 可设「最长等待」「调用上限」控制时间与计费预算，超预算带当前最优结果收场。
     注意这是**软上限**：只在轮与轮之间、每个候选开跑前检查，当前候选会跑完，
     最坏可超约 2~4 分钟；收稿前的安全核查不受时限取消。
  ⑤ v0.9.14 新增「严格保真」（默认关闭）：开启后交付前对最终稿再做一次独立事实
     核查，发现编造即拒绝交付并回退本地引擎。核查有漏判率，不担保干净。
  SenseNova 用户专享（dev/桌面版）：Base URL 填 /sensenova/v1，模型填
  deepseek-v4-flash（主力）/ deepseek-v4-pro（备选）/ glm-5.2（交叉评判）。
  注意：相对路径 Base URL 只在 dev（vite 代理）或 Electron 桌面版可用；
  静态托管 dist 的用户需自备反代，或改填 CORS 放行的服务商。

六、去味强度怎么选 & 指纹体检
  没有 API：用「去味强度」滑块，本地引擎处理（0.6 起步，0.9 最狠）；
  配了 API：深度模式接管（改写+质检+评判每轮实时显示评分）。
  「指纹体检」面板查 7 类可被统计抓到的痕迹（空格指纹/句长方差/垫词复读等）。

六之二、多文件批量（v0.9.64 起）
  「导入」可直接多选 .txt / .md / .docx，自动进批量面板：逐篇跑、显示前后分，
  失败行可单独重试，运行中可「停止」再续跑。
  右下「打包下载」出一个 ZIP：**首条是 00-批量报告.md**（逐文件的本地前后分），
  其余是每篇的 .humanized.txt，条目带序号不会互相覆盖。

六之三、外部检测器（可选，不绑定任何厂商）
  设置 → 对标检测器：填任意「POST {text} → JSON」的接口地址，按点路径取分
  （默认 0-100 刻度，0~1 的接口把刻度改成 0-1）。存成「我的预设」可多档切换。
  批量面板里勾「用外部检测器打前后分」后，每篇会额外送检（每档 2 次：原文+产出），
  行内显示「本地 10 → 2 · 外部 42 → 31」——本地分是代理分，外部才是可比的真值。
  报告清单里各档各占一列；没送检的写「未送检」，不会拿本地分冒充。
  各档若需要不同 Key，请用 CLI：--detector-url 可重复，--detector-key 跟随最近一档。

七、隐私
  本地引擎：原文只在你设备上处理，绝不上传。
  API 模式：原文会发给你自己配置的服务商，Key 只存浏览器 localStorage。
  本工具不收集任何数据。

八、常见问题
  Q: 双击 bat 没反应？
  A: 没装 Node.js，先跑「环境依赖安装.bat」。
  Q: 端口被占用（5173）？
  A: 关掉旧的「QuAiWei 引擎」窗口再启动。
  Q: "API 调用失败，已回退本地引擎"？
  A: 检查 Key / Base URL / 模型名是否可达；限流会自动换 Key 轮换重试，
     反复失败可稍后再试或先用本地档。

九、桌面版（可选）
  cd electron-app && npm install
  npm start
  打包：npx electron-packager . QuAiWei --platform=win32 --arch=x64 --out=../electron-dist
